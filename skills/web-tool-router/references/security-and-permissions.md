# 安全与权限

## 权限清单

- **读取**：读取用户明确提出的公开网页和公开平台数据。只有私有配置允许、用户授权本次认证读取且目标站点表面明确时，才能借用既有专用浏览器会话。
- **写入**：默认不写入外部网站；本地只向任务工作区或用户指定目录写入必要结果。不得发布、评论、点赞、关注、上传、提交表单或修改账号。
- **网络**：只调用私有配置中启用且已经审查的后端。URL、查询和公开页面内容只能发送给完成当前任务所需的后端。
- **凭据**：不得导出、复制、打印或上传 Cookie、Token、授权头、浏览器资料、代理凭据和登录诊断。不得从其他浏览器、profile、密码库或配置文件中寻找替代凭据。
- **费用与额度**：公开默认禁止付费/API-credit 后端、SocialCrawl 和任何会消耗额度的隐藏回退。
- **外部状态**：只读检索仍可能触发站点限流或创建临时浏览器页面；默认有限重试，并只关闭明确属于当前工作流的页面。

## 最终确认边界

显式调用本 Skill 只授权公开只读检索，不授权认证、扫码、登录、验证码处理、私有内容、账号动作、发布、上传、付费、代理修改、软件安装或升级。认证读取必须在本次任务中获得授权；任何外部写入或付费路线必须另行请求并在动作前确认。

## 隔离与日志

一个任务只允许一个浏览器会话所有者。其他自动化使用独立临时 profile，不能附着到登录 profile。任务日志不得包含真实 profile 标识、窗口注册表、Cookie、Token、完整授权 URL、私有 URL、代理信息或账号标识。
