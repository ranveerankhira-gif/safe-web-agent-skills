# 淘宝与天猫官方客户端查验

淘宝、天猫的商品、评价、规格、店铺和价格，默认使用用户已经登录的淘宝官方桌面客户端。不要自动启动、恢复或反复尝试 `taobao-login` 专属浏览器；只有用户在当前任务中明确要求该例外时才允许使用。

## 商品与评价

1. 在客户端打开目标商品，先核对商品 ID、标题、店铺和目标颜色尺码；相似商品或其他标签页的评价不得混入。
2. 客户端自带只读 CLI 可用时优先使用；若它明确返回远程关闭，可在用户已授权当前任务、客户端仅监听 `127.0.0.1` 调试端口时，使用 `scripts/taobao-client-reader.cjs` 的 loopback CDP 只读路径。不得修改客户端 `remote-config.json`，也不得把调试端口永久写入快捷方式。
3. 客户端当前不在目标商品页、且用户已授权购买前自动化时，可运行 `node scripts/taobao-client-reader.cjs open-item <商品ID> --confirm OPEN_ITEM:<商品ID>`，它只接受纯数字商品 ID 并固定打开天猫商品地址；命令级确认口令只能在取得本次任务授权后填写，不能替代用户授权。若出现验证立即暂停，不得处理验证。随后运行 `status` 核对商品 ID、店铺、页面状态与只读接口；运行 `reviews [页码]` 读取单页，或运行 `audit` 逐页读取所有可访问正文并单独返回负评与追评。读取器不得输出 Cookie、签名或账号令牌。
4. 记录页面宣称量、接口精确量、追评量、图/视频量、实际取得量和筛选标签。`100+` 与接口的 `100` 分开保存；读取器去重后的取得量可能因实时排序变动与展示总量不同，不能互相冒充。
5. 所有可访问负面正文都要逐条读完。没有“差评”按钮不等于零差评；成功空数组也不是零差评证据。分页、实时排序、变体混评、折叠评价或内容截断必须写入 `limitations`。

## 价格

- 先选择与候选完全一致的颜色、尺码和数量，再记录价格。
- 用户在当前任务中明确要求自动化购买前流程时，助手应使用正常页面或受限的 `diannao-kongzhi` 自动打开目标商品、核对商品 ID、选择准确变体和数量、加入购物车，再打开购物车读取目标条目；不得把这些普通步骤退回给用户。
- 官方客户端页面已精确选中目标 SKU、但 UI Automation 不暴露加购按钮时，可在用户逐项确认平台、商品、规格和数量 1 后运行 `node scripts/taobao-client-reader.cjs add-cart <商品ID> <SKU> 1 --confirm ADD_CART:<商品ID>:<SKU>:1`。目前脚本只支持数量 1；其他数量改用受限 UI 流程并重新确认。命令级确认口令不能替代用户确认。命令必须同时核对当前 URL、页面所选属性路径、SKU 和页面加购许可，并且只能调用唯一可见的“加入购物车”DOM 控件；随后必须用 `cart-price <商品ID>` 在购物车按目标商品 ID 验证，不能仅凭点击成功宣称已加购。
- `1??`、`2??` 仍不是精确价格。目标变体由用户或助手加入购物车后，可只读核对该条目的店铺优惠后单价，并与划线价、消费券、跨店优惠和最终结算价分开记录。
- 购物车页面已经打开、且目标商品 ID 已加入购物车时，可运行 `node scripts/taobao-client-reader.cjs cart-price <商品ID>`。输出必须只包含目标条目；`￥3??` 之类模糊值不得被解析成 `￥3`。
- 自动化不得领取优惠、勾选结算、进入结算或提交订单；不得读取或改变购物车中的无关商品。购物车未勾选时显示的单价不能冒充最终支付金额。

## 会话与错误边界

- 客户端操作只使用环境允许的安全 UI 或客户端自带只读接口；不得用坐标点击、按键注入、导出 Cookie 或绕过验证码。
- 客户端页面无法安全控制时记 `CLIENT_CONTROL_UNAVAILABLE`；商品或评价组件没有渲染时记 `CLIENT_PAGE_UNAVAILABLE`。这两者都不是零差评，也不能称为整个平台风控。
- `pcIdentityRisk=true` 或 `pcResistDetail=true` 是页面限制信号，不自动等于评论读取失败。只读评价接口成功返回正文时如实记录风险信号与成功结果；接口同时返回验证、流量限制或账号挑战时才记 `PLATFORM_SESSION_RESTRICTED`。预览卡、空数组、`about:blank` 和缺少评论 DOM 都不能证明零差评。
- 看到验证码、滑块、短信验证、设备确认、人脸认证或账号异常提示时立即暂停自动操作，等待用户正常完成；用户确认完成后，从最近的已验证状态自动续跑，不把搜索、规格选择、加购或读价再次交给用户。
- 调试端口只能临时绑定 loopback。任务结束后关闭调试模式客户端并正常重启，确认登录态仍在；不要让 `9223` 或其他调试端口长期开放。
- 调试客户端把窗口关闭解释为缩到托盘、无法通过受限 UI 正常退出时，可在确认目标确为本次临时调试客户端后运行 `node scripts/taobao-client-reader.cjs close-debug --confirm CLOSE_DEBUG_CLIENT`，通过已经验证为 loopback、端口完全匹配且不含凭据的 CDP 请求客户端正常关闭；命令级确认口令不能代替目标核验。不得以此关闭其他浏览器或改用强制结束进程。随后从无调试参数的官方快捷方式重启并确认调试端口已关闭。
- `review_coverage.access_mode` 使用 `official_client`；登录后读取须在对应 `access_attempts` 中写 `authorization: "current_task"`。`reader_evidence.backend` 写实际客户端与读取方式，不能伪装成 OpenCLI。
