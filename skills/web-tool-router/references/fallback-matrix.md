# 回退矩阵

实际顺序以仓库外私有配置为准。下列工具只是可替换示例，不代表必须安装，也不能覆盖用户明确指定的后端。

| 需求 | 首选能力 | 可选免费工具示例 | 停止条件 |
|---|---|---|---|
| 公开搜索 | 搜索 API/CLI 的结构化结果 | Ketch、用户配置的公开搜索后端 | 所有已配置后端在有界重试后仍失败 |
| 已知 URL 正文 | 无登录静态提取 | Ketch、Crawl4AI | 登录、验证码、私有内容或付费墙 |
| JavaScript 动态页 | 隔离的只读浏览器 | Playwright 或无登录 OpenCLI 会话 | 登录门槛、账号挑战或浏览器桥故障 |
| GitHub 公开数据 | 官方 CLI/API 或公开页面 | `gh`、Ketch code | 私有仓库或认证资源 |
| YouTube 字幕/元数据 | 字幕与公开元数据提取 | `yt-dlp` | 无字幕、内容受限或需登录 |
| Bilibili 公开信息 | 公开平台适配器 | `bili`、Agent Reach 检测到的后端 | 登录或账号挑战 |
| 微信视频号内容 | `$resource-fetcher-router` 验证媒体 | 获授权的既有 OpenCLI 登录会话 | 媒体路由失败且无授权会话；匿名二维码页不是回退 |
| X/Reddit/小红书 | 已配置且获授权的唯一登录会话 | OpenCLI | 登录失效、验证码或 auth surface 不匹配 |

只有超时、DNS、连接重置、HTTP 5xx 和有限的 HTTP 429 可以触发自动回退。不得添加付费服务、SocialCrawl、未经审查的抓取器或会静默读取其他浏览器资料的工具。
