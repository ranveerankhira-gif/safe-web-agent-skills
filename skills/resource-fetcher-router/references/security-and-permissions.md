# 安全与权限

## 权限清单

- **读取**：用户明确给出的公开查询、公开 HTTPS URL、候选目录、私有配置路径，以及用户指定的本地媒体。不得扫描浏览器资料、聊天记录、下载历史、密钥目录或其他账号数据。
- **写入**：下载时只向用户指定输出根目录下的新运行目录写入媒体与最小验证记录；同名不同内容不覆盖。发现和探测模式不得写文件。
- **网络**：网络请求由用户自行安装并审查的下载器执行。只把完成当前任务所需的公开查询或 URL 交给已配置后端，不上传本地文件、捕获流量或设备信息。
- **凭据**：默认不需要也不读取凭据。登录、Cookie、Token、授权头、浏览器会话、代理凭据、P2P 账号或验证码需求出现时停止；只有用户明确选择相应工作流后才能继续。
- **费用与额度**：默认仅使用用户已配置的免费后端。不自动启用付费 API、云转码、代理、P2P 或会消耗额度的服务。
- **外部状态**：下载会访问第三方站点并创建本地文件，可能触发限流。默认串行、有限重试，不发布、不点赞、不评论、不关注、不修改账号或远端内容。

## 最终确认边界

以下动作必须由用户明确要求：开始下载、启用新的后端、批量或并发获取、使用 P2P、使用已登录会话、付费、代理变更、转码覆盖或任何账号动作。登录、二维码、验证码、DRM、私有内容、付费墙和区域限制不能通过“换工具”静默绕过。

## 文件边界

输出根目录必须是明确的绝对路径。每次下载使用新的子目录；拒绝路径越界、符号链接、Windows 重解析点和同名覆盖。任何清理都只能针对带本工具所有权标记、位于受控临时根目录内的目录；此公开 Skill 默认不执行递归删除。

## 日志与证据

日志不得包含 Cookie、Token、授权头、完整环境变量、登录态、代理凭据或私有 URL。标题、封面、成功退出码和下载器文字都不是内容证据；证据等级与媒体结果格式见 [路由器接口](router-contract.md)。
