# 安全与权限

本 Skill 是高权限购物调研工具，但安装本身不授权登录、购物车变更或长期保存偏好。三类能力必须分别授权。

## 默认只读模式

- **读取**：访问公开商品页、评价、投诉、品牌与售后信息；读取用户在当前任务中明确提供的预算、用途和约束。
- **网络**：使用公开网页与已声明的免费本地联网工具。禁止付费 API、返佣、推广和未经审计的抓取服务。
- **写入**：默认不写长期状态。临时工作文件只能位于当前任务工作区或用户指定目录。
- **凭据**：不索取、记录、导出或传递密码、Cookie、Token、支付资料和完整地址。
- **费用**：不提交订单、不付款、不购买样本或服务。

## 登录态读取

只有用户在当前任务中明确授权后，才可复用已经配置好的官方客户端或专用会话，读取登录后正常可见的商品、评价、问答、售后和购物车目标条目价格。不得代用户登录、扩大到无关账户页面或绕过验证码、滑块、短信验证、设备确认和人脸认证。

登录态读取不授权加入购物车，也不授权长期保存购物偏好。

## 可逆购买前操作

选择变体、调整数量或加入购物车前，必须向用户列明平台、商品、准确规格和数量，并取得当前任务对这些对象的明确授权。每次状态改变后用商品 ID、规格文字和目标购物车条目复核。

以下动作始终不在范围内：提交订单、付款、领取优惠、删除或清空购物车、修改其他已有条目、联系商家、点赞、收藏、评价和卖家操作。

## 长期记录

长期记录默认关闭。只有用户明确选择启用并提供仓库外私有状态目录时，才可运行 `shopping_memory.py commit`。

- 使用 `--state-root <private-state-root>` 或环境变量 `SHOPPING_RESEARCH_STATE_ROOT`。
- 状态目录必须位于 Skill、共享 Skills、代码仓库及其配置容器之外，并带有脚本生成且内容匹配的所有权标记；符号链接、Windows 联接点和其他重解析点一律拒绝。
- 已存在且非空、但没有正确所有权标记的目录拒绝写入。
- 实际状态目录、记录、账号配置、Cookie 和日志不得提交到公开仓库或打入发行包。
- 记录写入前会过滤账号、完整地址、订单号、电话、身份证、支付信息、收礼人姓名、Cookie 和 Token；过滤机制不能代替最小化收集。

## 最终确认边界

| 动作 | 默认 | 所需授权 |
|---|---|---|
| 公开网页调研 | 允许 | 显式调用本 Skill |
| 复用登录态读取 | 禁止 | 当前任务明确授权 |
| 选择变体、调整数量、加入购物车 | 禁止 | 对平台、商品、规格和数量逐项确认 |
| 保存长期偏好与调研历史 | 禁止 | 明确启用并配置仓库外状态目录 |
| 提交订单、付款或处理凭据 | 永久禁止 | 不接受授权扩展 |
